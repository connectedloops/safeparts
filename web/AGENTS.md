# AGENTS.md — Web App

## Purpose

Owns the Vite + React browser UI, web packaging, WASM build integration, and local web tests.

## Ownership

- `src/`: React application, components, hooks, i18n, styles, and generated WASM package boundary.
- `scripts/`: WASM helpers, combined static-site build, and deployment artifact verification.
- `tests/`: Playwright/axe browser tests and Docker runtime smoke coverage.
- `help/`: Astro + Starlight documentation site; see its child AGENTS.md.
- `Dockerfile`, `docker/`, `nginx.conf`, `public/`, `cloudflare-worker.ts`, and package config for static deployment.

## Local Contracts

- The web UI must keep split/combine workflows local to the browser; do not introduce a backend for secrets.
- Supported interfaces are web/help, CLI, and TUI over core/WASM. Downloads distinguish supported CLI/TUI archives from unsupported historical GUI installers; retained desktop/native applications and their UniFFI bridge are dormant.
- Standard browser suites exclude `tests/desktop-*.spec.ts` and start only web/help servers. With `PLAYWRIGHT_BASE_URL`, use an external server; built-site checks use a plain static server, not Vite preview's help proxy.
- `src/wasm_pkg/` is generated by `bun run build:wasm`; avoid hand-editing generated artifacts except when explicitly required.
- User-facing docs under `help/` require the `humanizer` skill before finalizing prose edits.
- Publishable local output comes from `mise run web:build:site` (or `bash web/scripts/build-site.sh` from the root). Standalone Vite builds clear `dist/`, including help; standalone help builds replace only `dist/help/`. Keep these writers sequential.

## Work Guidance

- Follow `docs/agents/conventions.md` for React/TypeScript style and user-friendly error handling.
- Use the `frontend-design` skill for UI construction or substantial visual redesign.
- For browser-based Web UI checks, use the `browser` skill / `browse` CLI in local mode unless the user explicitly asks for Playwright.

## Verification

- Install: `bun install --frozen-lockfile`
- Build WASM: `bun run build:wasm`
- Test WASM browser bindings: `bun run test:wasm`
- Type check: `bun run typecheck`
- Build app only: `bun run build`
- Build and verify the combined app/help artifact: `bash scripts/build-site.sh`
- Dev server: `bun run dev`
- Existing test scripts: `bun run test:e2e:smoke`, `bun run test:e2e:full`, `bun run test:container`
- Deployment package policy: `python3 ../scripts/dev/test_web_deploy.py`

## Child DOX Index

- `src/`: React browser app source and generated WASM package boundary.

- `tests/`: Playwright/axe browser and docs tests plus Docker runtime smoke coverage.
- `help/`: Astro/Starlight help documentation site deployed under `/help/`.
