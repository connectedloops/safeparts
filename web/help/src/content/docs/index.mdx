Safeparts splits a secret into recovery shares. In a 2-of-3 plan, two distinct, valid shares from the same split can restore it. If you enable passphrase protection, you also need the original passphrase.

Use these docs to choose a recovery plan, pick an interface, and avoid common handling mistakes.

## What Safeparts does

- Splits arbitrary bytes with Shamir-style threshold sharing over <span class="token token--mono">GF(256)</span>.
- Checks set metadata and a BLAKE3 integrity tag to reject mixed sets and detect corruption. These checks [do not authenticate the sender](technical-design/#integrity-tag).
- Can encrypt before splitting with Argon2id and ChaCha20-Poly1305 when you add a passphrase.
- Exposes the same core through CLI, TUI, WASM, web, and Rust APIs.

Safeparts is not a vault, password manager, or wallet seed tool. Your storage plan is still the security boundary.
