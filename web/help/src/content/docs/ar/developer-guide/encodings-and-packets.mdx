يعيد التقسيم قيماً ثنائية من نوع `SharePacket`. يجب على معظم التطبيقات ترميز الحزم قبل التخزين أو العرض أو النقل.

## ترميز الحزم

استخدم `safeparts_core::encoding` كواجهة الترميز النصي العامة.

```rust
use safeparts_core::encoding::{self, Encoding};
use safeparts_core::{split_secret, CoreResult};

fn encode_for_storage() -> CoreResult<Vec<String>> {
    let packets = split_secret(b"synthetic storage secret", 2, 3, None)?;

    packets
        .iter()
        .map(|packet| encoding::encode_packet(packet, Encoding::Base64url))
        .collect()
}
```

`Encoding::Auto` للتحليل فقط. يجب أن يختار الخرج ترميزاً محدداً، لا `Encoding::Auto`.

## تحليل مدخلات ملصقة

```rust
use safeparts_core::encoding::{self, Encoding};
use safeparts_core::{combine_shares, CoreResult};

fn recover_from_paste(input: &str) -> CoreResult<Vec<u8>> {
    let parsed = encoding::parse_share_packets(input, Encoding::Auto)?;
    combine_shares(&parsed.packets, None)
}
```

لمناطق النص وملفات حصص CLI بالكلمات، استخدم `parse_share_packets_wrapped_mnemonics`. تحاول الدالة أولاً فك ترميز كل سطر غير فارغ كحصة استرداد كاملة مع التحقق الصارم. إذا فشل ذلك، تفصل الأسطر الفارغة بين حصص الاسترداد الموزعة على عدة أسطر. تقبل الطريقتان نهايات الأسطر <span class="token" dir="ltr">LF</span> و<span class="token" dir="ltr">CRLF</span>. تؤدي الكلمات والإطارات غير الصالحة، بما فيها إطارات <span class="token" dir="ltr">BIP-39</span> الفارغة، إلى خطأ بدلاً من تجاهلها.

## الترميزات المدعومة

| الترميز | الاستخدام |
| --- | --- |
| `Encoding::Base64url` | نص مضغوط وآمن للروابط. |
| `Encoding::Base58check` | نص مضغوط مع checksum من Base58Check. |
| `Encoding::MnemoWords` | مجموعات كلمات مع CRC16 للإدخال اليدوي. |
| `Encoding::MnemoBip39` | تسلسلات كلمات BIP-39 صالحة لمسارات التخزين المتوافقة. |
| `Encoding::Auto` | كشف parse-only لمدخلات المشغلين. |

## بيانات الحزمة

تحتوي كل `SharePacket` على:

- `set_id`: معرّف عشوائي لمجموعة التقسيم؛
- `k` و`n`: العتبة وإجمالي عدد الحصص؛
- `x`: إحداثي الحصة؛
- `payload`: بايتات الحصة؛
- `crypto_params`: معلمات Argon2id وnonce الاختيارية للتقسيمات المشفرة.

البيانات الوصفية مثل `set_id` و`k` و`n` و`x` و`crypto_params` ليست سرية. تساعد الاسترداد على رفض مجموعات مختلطة وفهارس مكررة ومعلمات تشفير غير متوافقة. أما بايتات الحصة في الحقل `payload` فهي مادة حساسة ولا يجوز نشرها أو تسجيلها.

## نمط تخزين

تدفق شائع في التطبيقات:

1. قسّم البايتات إلى قيم `SharePacket`.
2. رمّز كل حزمة بترميز محدد واحد.
3. خزّن كل حصة مرمزة في نطاق فشل منفصل.
4. خزّن اسم الترميز مع البيانات الوصفية للحيازة إذا لن يستخدم المشغلون الكشف التلقائي.
5. لاحقاً حلل على الأقل <var>k</var> حصص مرمزة.
6. ادمج الحزم وتعامل مع البايتات المستعادة كناتج حساس.

يجب أن يحتفظ كل نطاق تخزين وكل نطاق إدارة بعدد من الحصص أقل من العتبة، بما يشمل قواعد البيانات والخزائن ومخازن أسرار CI. لا تسجّل الحصص مطلقاً. اجمع حصصاً كافية فقط أثناء جلسات إعداد أو تحقق أو استرداد مؤقتة ومعتمدة، ثم احذف المواد المؤقتة وأعد فصل الحيازة. أكمل [نقطة التحقق من النسخة المحفوظة](../../it-devops-guide/break-glass/#verify-saved-backup) قبل الاعتماد على الحصص المحفوظة.
