اسم الملف التنفيذي لواجهة TUI هو <span class="token token--mono" dir="ltr">safeparts-tui</span>. يمكنك تشغيلها أيضاً عبر CLI باستخدام <span class="token token--mono" dir="ltr">safeparts tui</span>.

استخدم TUI عندما تريد سير عمل موجهاً داخل الطرفية، وتشغيلاً دون اتصال، ودعم الحافظة، وإجراءات تحميل أو حفظ للملفات.

## ماذا تدعم TUI

- سير التقسيم والاسترداد.
- الترميزات الأربعة المدعومة: <span class="token" dir="ltr">base64url</span> و<span class="token" dir="ltr">base58check</span> و<span class="token" dir="ltr">mnemo-words</span> و<span class="token" dir="ltr">mnemo-bip39</span>.
- كشف تلقائي عند الاسترداد.
- عبارات مرور اختيارية.
- تحميل ملفات الأسرار أو ملفات الحصص.
- تصدير ملف لكل حصة أو حفظ البايتات المستعادة.

## إدخال حصص الاسترداد

في تبويب الاسترداد، الصق حصص الاسترداد أو اضغط <span dir="ltr"><kbd>Ctrl</kbd>+<kbd>L</kbd></span> لتحميل ملفاتها. عند استخدام <span class="token" dir="ltr">mnemo-words</span> أو <span class="token" dir="ltr">mnemo-bip39</span>، تقبل واجهة الطرفية:

- حصة استرداد كاملة في كل سطر، بما في ذلك ملف ناتج من CLI. لا تحتاج إلى إضافة أسطر فارغة أو إعادة كتابة الملف.
- حصة استرداد موزعة على عدة أسطر. افصل بين الحصص الموزعة على عدة أسطر بسطر فارغ.

تعمل الطريقتان مع الكشف التلقائي عن الترميز أو اختيار الترميز المطابق، ومع نهايات الأسطر <span class="token" dir="ltr">LF</span> أو <span class="token" dir="ltr">CRLF</span>. يمكنك إدخال عدد من حصص الاسترداد يساوي العتبة أو يزيد عليها، بشرط أن تكون من المجموعة نفسها. ترفض واجهة الطرفية الحصص التالفة أو المكررة والحصص من مجموعات مختلفة بدلاً من تجاهلها.

عند استخدام <span class="token" dir="ltr">base64url</span> أو <span class="token" dir="ltr">base58check</span>، افصل بين حصص الاسترداد بمسافات أو أسطر جديدة.

## سير عمل دون اتصال

<Steps>
1. استخدم جهازاً مفصولاً عن الشبكة إذا كان الإجراء يتطلب ذلك.
2. شغّل <span class="token token--mono" dir="ltr">safeparts-tui</span>.
3. اختر عدد الحصص المطلوبة، وإجمالي عدد الحصص، والترميز.
4. أدخل السر أو حمّله.
5. قسّم وصدّر الحصص إلى وسائط أو حاملين منفصلين.
6. قبل التخلص من نسخة العمل أو الاعتماد على النسخة الاحتياطية، أكمل [نقطة التحقق من النسخة المحفوظة](../it-devops-guide/break-glass/#verify-saved-backup) باستخدام نسخ الحيازة الفعلية. إذا لم تسمح السياسة بالتحقق، فاحتفظ بنسخة العمل واترك الإعداد غير مكتمل.
</Steps>

التشغيل دون اتصال لا يفيد إلا إذا بقيت الحيازة منفصلة. احتفظ بعدد من حصص الاسترداد أقل من العتبة في كل حساب وجهاز وموقع ونطاق إدارة وقناة نقل.

## إذا فشلت عملية ملف

إذا كان الملف مفقوداً أو غير قابل للقراءة، أو كان المسار غير صالح، أو تعذرت الكتابة إلى الوجهة، تعرض TUI خطأ بدلاً من إغلاق الجلسة. تحقق من المسار وأذونات الملف، ثم اضغط <span dir="ltr"><kbd>Ctrl</kbd>+<kbd>L</kbd></span> لإعادة فتح التحميل، أو <span dir="ltr"><kbd>Ctrl</kbd>+<kbd>S</kbd></span> لاختيار وجهة حفظ والمحاولة مجدداً.

يحافظ فشل التحميل على إدخال السر أو حصص الاسترداد السابق. عند تحميل عدة ملفات لحصص الاسترداد، تحدد الرسالة الملف الذي فشلت قراءته بحسب ترتيبه في القائمة. لا تستبدل TUI الإدخال إلا بعد قراءة جميع الملفات. يجب أن تحتوي ملفات حصص الاسترداد على نص بترميز UTF-8.

يحافظ فشل الحفظ على حصص الاسترداد الناتجة أو السر المستعاد. إذا توقف التصدير أثناء التنفيذ، تعرض الرسالة رقم حصة الاسترداد التي تعذر حفظها وعدد الملفات التي حُفظت. تبقى هذه الملفات على القرص. تُكتب الملفات بصورة ذرية كلٌّ على حدة، وليس كمجموعة واحدة. تحقق من الملفات المكتملة قبل إعادة المحاولة، وحافظ على فصل حيازتها.

تقرأ TUI ملف السر المحمّل مرة أخرى عند التقسيم. إذا فشلت القراءة، أعد الملف ثم اضغط <kbd>Enter</kbd> للمحاولة مجدداً، أو حمّل ملفاً آخر. لا تعرض رسائل أخطاء الملفات المسارات أو المحتويات الحساسة. أما أعطال الطرفية الجسيمة فتنهي الجلسة مع محاولة استعادة إعدادات الطرفية.

## اختصارات لوحة المفاتيح

عندما يكون التركيز على حقل نصي، تُكتب فيه المحارف القابلة للطباعة مثل <kbd>?</kbd>. في محرري السر وحصص الاسترداد، تحرّك مفاتيح الأسهم المؤشر داخل النص. تدعم حقول عبارة المرور الكتابة والحذف باستخدام <kbd>Backspace</kbd> والمسح باستخدام <span dir="ltr"><kbd>Ctrl</kbd>+<kbd>U</kbd></span>.

| المفاتيح | الإجراء |
| --- | --- |
| <span dir="ltr"><kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd></span> | نقل التركيز. |
| <span dir="ltr"><kbd>Alt</kbd>+<kbd>Left</kbd> / <kbd>Alt</kbd>+<kbd>Right</kbd></span> | التبديل بين تبويبي التقسيم والاسترداد. |
| <span dir="ltr"><kbd>Left</kbd> / <kbd>Right</kbd> / <kbd>Up</kbd> / <kbd>Down</kbd></span> | تحريك المؤشر في المحرر متعدد الأسطر الذي عليه التركيز. |
| <span dir="ltr"><kbd>Up</kbd> / <kbd>Down</kbd></span> | تعديل الإعداد الرقمي أو ترميز الحصص أو اختيار حصة الاسترداد عندما يكون التركيز على ذلك العنصر. |
| <kbd>Enter</kbd> | تنفيذ التقسيم أو الاسترداد. |
| <span dir="ltr"><kbd>Ctrl</kbd>+<kbd>L</kbd></span> | تحميل ملف سر أو ملفات حصص. |
| <span dir="ltr"><kbd>Ctrl</kbd>+<kbd>S</kbd></span> | الحفظ أو التصدير. |
| <span dir="ltr"><kbd>Ctrl</kbd>+<kbd>C</kbd></span> | نسخ حصة الاسترداد المحددة أو السر المستعاد. |
| <span dir="ltr"><kbd>Ctrl</kbd>+<kbd>V</kbd></span> | اللصق في المحرر الذي عليه التركيز عندما تتوفر الحافظة. |
| <span dir="ltr"><kbd>Ctrl</kbd>+<kbd>U</kbd></span> | مسح حقل عبارة المرور الذي عليه التركيز. |
| <kbd>F1</kbd> | فتح المساعدة من أي حقل أو عنصر تحكم خارج النافذة المنبثقة. |
| <kbd>Esc</kbd> | إغلاق المساعدة أو إلغاء نافذة. |
| <span dir="ltr"><kbd>Ctrl</kbd>+<kbd>Q</kbd></span> | الخروج. |
