يمكن أن يكون Safeparts جزءاً من الأتمتة، لكنه لا ينبغي أن يتحول إلى نظام توزيع أسرار online روتيني. استخدمه للإعداد وescrow وتدريبات الاسترداد والاسترداد المعتمد من المشغلين. استخدم مدير أسرار للحقن الروتيني وقت التشغيل.

شغّل فحوص CI المتكررة باستخدام أسرار اصطناعية. لا تضع حصصاً إنتاجية أو عبارات مرور أو اعتمادات مستعادة في سجلات CI أو artifacts أو caches أو لقطات شاشة أو تذاكر.

## قواعد scripts

- أبقِ `set -x` معطلاً حول الأوامر التي تلمس الأسرار أو الحصص أو عبارات المرور أو الناتج المستعاد.
- استخدم stdin والملفات بدلاً من القيم الحرفية في سطر الأوامر للمواد الحساسة.
- فضّل `--passphrase-file` على `--passphrase`.
- أنشئ الملفات المؤقتة داخل مجلد خاص مع `umask 077`.
- احتفظ بعدد حصص أقل من العتبة في كل CI secret store وbucket artifacts وrepository ونطاق هوية. لا تجمع الحصص مؤقتاً إلا في جلسة معتمدة ومتحكم بها تتبعها عملية تنظيف.
- لا تطبع الأسرار المستعادة. قارن الملفات أو مرر البايتات مباشرة إلى خطوة واحدة متحكم بها.

## تدريب اصطناعي محلي

يتحقق هذا script من تقسيم واسترداد 2 من 3 دون طباعة القيمة المستعادة.

```bash
#!/usr/bin/env bash
set -euo pipefail
umask 077

workdir="$(mktemp -d)"
trap 'rm -rf "$workdir"' EXIT

printf 'synthetic secret for automation drill' > "$workdir/secret.bin"

safeparts split \
  -k 2 \
  -n 3 \
  -e base64url \
  -i "$workdir/secret.bin" \
  -o "$workdir/shares.txt"

sed -n '1,2p' "$workdir/shares.txt" > "$workdir/selected-shares.txt"

safeparts combine \
  -i "$workdir/selected-shares.txt" \
  -o "$workdir/recovered.bin"

cmp "$workdir/secret.bin" "$workdir/recovered.bin"
```

يعلّم هذا التدريب التقسيم والاسترداد، لكنه لا يتحقق من نسخة احتياطية حقيقية. قبل التخلص من نسخة العمل، اتبع [نقطة التحقق من النسخة المحفوظة](../break-glass/#verify-saved-backup). أبقِ الأمثلة هنا اصطناعية.

## تدريب محمي بعبارة مرور

```bash
#!/usr/bin/env bash
set -euo pipefail
umask 077

workdir="$(mktemp -d)"
trap 'rm -rf "$workdir"' EXIT

printf 'synthetic protected secret' > "$workdir/secret.bin"
printf '%s' 'synthetic passphrase for tests' > "$workdir/passphrase.txt"

safeparts split \
  -k 2 \
  -n 3 \
  -e mnemo-words \
  -P "$workdir/passphrase.txt" \
  -i "$workdir/secret.bin" \
  -o "$workdir/shares.txt"

awk 'NR <= 2 { print }' "$workdir/shares.txt" > "$workdir/selected-shares.txt"

safeparts combine \
  -P "$workdir/passphrase.txt" \
  -i "$workdir/selected-shares.txt" \
  -o "$workdir/recovered.bin"

cmp "$workdir/secret.bin" "$workdir/recovered.bin"
```

<h2 id="saved-backup-rehearsal">تدريب اصطناعي للنسخة الاحتياطية المحفوظة</h2>

شغّل هذا المثال باستخدام Bash وCLI المثبت وأدوات Unix المعتادة. يستخدم بيانات اصطناعية فقط، بما فيها سر ثنائي يحتوي بايت NUL. يقرأ ثلاثة ملفات محفوظة ويختبر المجموعتين <span dir="ltr">1/2</span> و<span dir="ltr">1/3</span> مع الحماية بعبارة مرور. ثم يختبر عبارة مرور خاطئة ونسخة محفوظة لسر مختلف: حتى حصص الاسترداد الصالحة قد تستعيد بايتات لا تطابق المصدر.

توجد ملفات الحيازة كلها في مجلد مؤقت واحد هنا لأن التدريب اصطناعي فقط. للمواد الحقيقية، اتبع جلسة التحقق المتحكم بها والحيازة المنفصلة في نقطة التحقق، ولا تستخدم ترتيب المجلد هذا. يحتفظ السكربت بنسخة العمل الاصطناعية عند كل فشل متوقع، ويصحّح النسخة الاحتياطية، ثم يعيد التحقق من كل حصة محفوظة قبل التخلص من نسخة العمل. يحذف إجراء الخروج التلقائي جميع بيانات التدريب؛ لا تستخدمه لنسخة عمل حقيقية يجب أن تبقى عند فشل الفحص.

```bash
# Synthetic saved-backup rehearsal
set -euo pipefail
set +x
umask 077
workdir="$(mktemp -d)"
trap 'rm -rf "$workdir"' EXIT

printf 'synthetic source\000with binary bytes\n' > "$workdir/source.bin"
printf '%s' 'synthetic rehearsal Passphrase' > "$workdir/passphrase.txt"
printf '%s' 'synthetic wrong Passphrase' > "$workdir/wrong-passphrase.txt"

save_copies() {
  # base64url CLI output has one Recovery share per line.
  for index in 1 2 3; do
    sed -n "${index}p" "$workdir/export.txt" > "$workdir/saved-$index.txt"
  done
  rm "$workdir/export.txt"
}
create_backup() {
  safeparts split -k 2 -n 3 -e base64url \
    -P "$workdir/passphrase.txt" -i "$1" -o "$workdir/export.txt"
  save_copies
}
verify_saved() {
  local passphrase_file="$1" other status
  for other in 2 3; do
    cat "$workdir/saved-1.txt" "$workdir/saved-$other.txt" > "$workdir/selected.txt"
    rm -f "$workdir/recovered.bin"
    status=0
    if safeparts combine -P "$passphrase_file" \
      -i "$workdir/selected.txt" -o "$workdir/recovered.bin" >/dev/null 2>&1; then
      cmp -s "$workdir/source.bin" "$workdir/recovered.bin" || status=$?
    else
      status=1
    fi
    rm -f "$workdir/selected.txt" "$workdir/recovered.bin"
    if [ "$status" -ne 0 ]; then return 1; fi
  done
}

create_backup "$workdir/source.bin"
verify_saved "$workdir/passphrase.txt"
printf '%s\n' 'PASS: saved shares 1,2,3 verified'

if verify_saved "$workdir/wrong-passphrase.txt"; then exit 1; fi
test -f "$workdir/source.bin"
printf '%s\n' 'PASS: wrong Passphrase blocked; working copy kept'

printf '%s' 'synthetic wrong source' > "$workdir/wrong-source.bin"
create_backup "$workdir/wrong-source.bin"
if verify_saved "$workdir/passphrase.txt"; then exit 1; fi
test -f "$workdir/source.bin"
printf '%s\n' 'PASS: saved-copy mismatch blocked; working copy kept'

create_backup "$workdir/source.bin"
verify_saved "$workdir/passphrase.txt"
rm "$workdir/source.bin"
printf '%s\n' 'PASS: corrected backup reverified before retirement'
```

يجب ألا تظهر إلا رسائل حالة ثابتة. غياب أي سطر PASS أو خروج السكربت بحالة غير صفرية يعني أن التدريب لم يكتمل. يختبر هذا الإجراء بالأوامر الموجودة؛ وليس ميزة للتحقق من النسخ الاحتياطية أو دليلاً على سلامة حصص الاسترداد الحقيقية لديك.

## تدريب CI

تدريب CI الآمن يستخدم بيانات اصطناعية ويثبت أن الكود الحالي ما زال ينفذ round-trip.

```yaml
name: safeparts synthetic recovery drill

on:
  workflow_dispatch:

jobs:
  recovery-drill:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable

      - name: Build CLI
        run: cargo build --release -p safeparts

      - name: Run synthetic drill
        shell: bash
        run: |
          set -euo pipefail
          umask 077

          workdir="$(mktemp -d)"
          trap 'rm -rf "$workdir"' EXIT

          printf 'synthetic CI drill secret' > "$workdir/secret.bin"
          target/release/safeparts split -k 2 -n 3 -e base64url -i "$workdir/secret.bin" -o "$workdir/shares.txt"
          sed -n '1,2p' "$workdir/shares.txt" > "$workdir/selected-shares.txt"
          target/release/safeparts combine -i "$workdir/selected-shares.txt" -o "$workdir/recovered.bin"
          cmp "$workdir/secret.bin" "$workdir/recovered.bin"
```

## استرداد حقيقي محروس

استخدم CI للاسترداد الحقيقي فقط بعد مراجعة أمنية. غالباً يوسّع runner الخاص بـ CI نطاق الوصول عبر السجلات ومتغيرات البيئة وcaches وartifacts ورؤية المسؤولين.

إذا كان يجب أن تدمج مهمة CI حصصاً حقيقية:

- شغّلها يدوياً؛
- استخدم runner مقوّى أو self-hosted؛
- اجمع الحصص للجلسة المعتمدة فقط ثم أعد فصل الحيازة؛ ولا تحتفظ بحصص كافية في backend أسرار واحد؛
- أخفِ المتغيرات، لكن لا تعتمد على masking كتحكم أساسي؛
- اكتب الناتج المستعاد إلى ملف خاص؛
- مرر الملف إلى خطوة واحدة مراجعة؛
- احذف الملفات المؤقتة عند الخروج؛
- دوّر الاعتماد المستعاد بعد الاستخدام.

## متى تستخدم مكتبة Rust

استخدم `safeparts_core` بدلاً من أتمتة shell عندما تحتاج إلى أخطاء typed، أو فحص metadata، أو تخزين مخصص، أو prompts داخل العملية، أو تحكم أدق في السجلات.
