# Generated artifacts

Generated files should be easy to refresh and review. Do not hand-edit generated output unless a task explicitly asks for it.

## Active artifact policy

| Path | Generated by | Tracked? | Rule |
| --- | --- | --- | --- |
| `CHANGELOG.md`, `web/help/src/content/docs/changelog.md`, `web/help/src/content/docs/ar/changelog.md` | `scripts/dev/changelog.py` | Yes | Generate and commit all three together; see [changelog workflow](../../scripts/dev/README.md#changelog-snapshots). CI uses main history, not branch HEAD. |
| `target/` | Cargo | No | Build output. Never edit or commit. |
| `dist/` | release scripts | No | Local release output. Never edit or commit. |
| `target/web-deploy/` | `web/scripts/deploy-artifact.py` | No | Local Web deployment package and retained evidence. Never commit. |
| `web/node_modules/` | Bun | No | Dependency install output. Never commit. |
| `web/dist/` | Vite, docs build, and `deploy-artifact.py` | No | Static build output. CI packages it as the commit-identified Web release unit after testing. Never commit. |
| `web/src/wasm_pkg/` | `web/scripts/build-wasm.sh` | No | Regenerate with `bun run build:wasm`. Do not hand-edit. |
| `web/help/node_modules/` | Bun | No | Dependency install output. Never commit. Preserve user-owned local links. |
| `web/help/dist/` and `web/help/.astro/` | Astro | No | Build/cache output. Never commit. |

## Dormant artifacts

Retired applications and their dedicated UniFFI bridge have no active generation or drift-check requirement. Retain these reference files without refreshing them for supported changes:

- `desktop/src-tauri/gen/schemas/`: partially tracked Tauri schemas.
- `macos/Generated/` and `macos/Sources/SafepartsKit/Generated.swift`: tracked Swift, header, and module-map outputs.
- `windows/Generated/safeparts_uniffi.cs`: tracked C# binding.
- Retained native manifests and lockfiles, including `desktop/bun.lock`.

Old native preparation commands are not supported after root workspace exclusion. Keep `desktop/node_modules/`, `desktop/dist/`, `macos/Native/`, `macos/.build/`, Windows `bin/` and `obj/`, and mobile dependency/build output untracked. Preserve user-owned files; retirement does not authorize cleanup or deletion.

## Refresh commands

WASM package:

```bash
cd web
bun run build:wasm
```

Complete web and help output, from the repository root:

```bash
bash web/scripts/build-site.sh
```

The app build clears `web/dist/`; the combined command builds help afterward and checks the final routes. For app-only and help-only commands, see [output semantics](verification.md#output-semantics).

Web deployment evidence is prepared only after WASM, application, help, and browser checks pass. See the [deployment guide](../deployment/web-artifact.md) for the credential-free package command. Netlify and Cloudflare consume this package without rebuilding source.

Help-only output:

```bash
cd web/help
bun run build
```

## Lockfiles

Bun is the package manager for web and help. Their tracked lockfiles are `web/bun.lock` and `web/help/bun.lock`. Do not add npm, pnpm, or yarn lockfiles unless the project deliberately changes package managers. Dormant package lockfiles remain reference, not active install requirements.

## Review checklist

Before committing:

```bash
git status --short
mise run dx:verify
```

Do not commit generated output unless this page says the path is tracked and the task requires its refresh.
