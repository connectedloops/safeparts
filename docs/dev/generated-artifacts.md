# Generated artifacts

Generated files should be easy to refresh and easy to review. Do not hand-edit generated output unless a task explicitly asks for it.

## Policy

| Path | Generated by | Tracked? | Rule |
| --- | --- | --- | --- |

| `dist/` | release scripts | No | Local release output. Never edit or commit. |

| `web/src/wasm_pkg/` | `web/scripts/build-wasm.sh` | No | Regenerate with `bun run build:wasm`. Do not hand-edit. |
| `web/help/node_modules/` | Bun | No | Dependency install output. Never commit. |

## Refresh commands

WASM package:

```bash
cd web
bun run build:wasm
```

Complete web and help output:

```bash
bash web/scripts/build-site.sh
```

Run this from the repository root. The app build clears `web/dist/`; the combined command builds help afterward and checks the final routes. For app-only and help-only commands, see [output semantics](verification.md#output-semantics).

Web deployment evidence is prepared only after WASM, application, help, and browser checks pass. See [`../deployment/web-artifact.md`](../deployment/web-artifact.md) for the credential-free package command. Netlify and Cloudflare consume this package without rebuilding source.

Help docs build output:

```bash
cd web/help
bun run build
```

Desktop frontend build output:

```bash
cd desktop
bun run build
```

Native macOS bindings:

```bash
mise run macos:prepare
cmp macos/Generated/safeparts_uniffi.swift macos/Sources/SafepartsKit/Generated.swift
```

The preparation script targets macOS 14 by default and strips trailing whitespace from generated text. You may set `MACOSX_DEPLOYMENT_TARGET` to a newer version for diagnostics. The script rejects versions older than 14.0.

Native Windows C# binding:

```bash
python3 windows/scripts/prepare.py
python3 windows/scripts/prepare.py --check
```

The Windows script builds the host Rust dynamic library and runs the C# generator at the exact revision recorded in the script. Windows CI compiles the binding and executes it against the real Windows DLL.

Tauri schemas are generated by the Tauri toolchain. If a Tauri upgrade or permission change updates `desktop/src-tauri/gen/schemas/`, review the diff and either commit the intentional schema update or remove local generated drift.

## Lockfiles

Bun is the JS package manager for web, docs, and desktop.

Tracked lockfiles:

- `web/bun.lock`
- `web/help/bun.lock`
- `desktop/bun.lock`

Do not add npm, pnpm, or yarn lockfiles for these packages unless the project deliberately changes package managers.

## Review checklist

Before committing:

```bash
git status --short
mise run dx:verify
```

Do not commit generated output unless this page says the path is tracked or the task explicitly requires it.
